Privacy

SlimRead has no account, no analytics, no telemetry, no advertising and no server of its own. There is nowhere for your data to go, because there is no “us” to send it to. This page lists exactly what is stored, where it lives, and how to remove it.

Last reviewed 4 October 2026. This describes SlimRead itself — the browser. The websites you visit through it have their own privacy practices, exactly as they would in Safari. SlimRead does not change, intercept or report what those sites do.

What is collected

Nothing. No personal data is gathered, transmitted or shared. The project has no backend, no database, no account system, no analytics and no crash reporting. Nobody — including the author — can see that you installed it, what you read, or that you exist.

What is stored on your device

All of it stays on the phone. None of it is transmitted anywhere.

Last page addressSo reopening returns you to where you were reading

What leaves the device

Only ordinary web requests, all of them ones you caused:

  • The site you are reading — page and image requests, over your own logged-in session, exactly as a browser makes them.
  • raw.githubusercontent.com — to fetch the reading script and stylesheet from this repository at launch. This is a plain file download; it carries no identifier and says nothing about you beyond what any file download reveals.
  • duckduckgo.com — only if you type something into the address bar that is not a web address, in which case it is treated as a search.

There are no other destinations. The reading script makes only same-origin requests to the site you are already on — no third-party endpoints, no beacons, no telemetry of any kind.

Third-party code

There is none. The app depends on no SDKs, frameworks or libraries beyond Apple's own. There is no advertising, attribution or analytics code anywhere in it. This website loads no fonts, scripts, trackers or resources from anyone else — every byte it serves comes from this repository.

Deleting everything

Delete the app. That removes all of the above — stored preferences, cached script, reading position and cookies — in one step, because every one of them lives inside the app's own container. Nothing survives it, and there is no server-side copy to request the deletion of.

To clear only the reading diagnostics while keeping everything else, open any page in the app with ?slimread=reset on the end of the address.

Children

SlimRead collects no data from anyone, of any age, so there is nothing to obtain consent for. It is a browser; the sites viewed through it have their own policies and age rules.
